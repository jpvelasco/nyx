# Provision a routed IPv4 segment

Use `nyx segment plan` or MCP `plan_segment` to preview a new access segment behind an OPNsense firewall with an Omada switching site. Select the two connections and the Omada site explicitly. Supply the segment role, VLAN tag, parent interface, static gateway with prefix, protected management prefix, permitted DNS resolver and DHCP range. `nyx segment apply` and `apply_segment` also preview by default. A real apply requires `--dry-run=false` or `dry_run: false`.

The report identifies each device's work, its dependencies and the effect on management access. Only one observed on-path router can own the change. The firewall creates the tagged interface, assigns its gateway, blocks IPv4 traffic from the new subnet to management, then permits DNS to the selected resolver. Nyx checks existing pass rules and preserves conflicting configuration for operator review. The firewall provisions the Dnsmasq range and Omada creates the VLAN-only LAN. A firewall without the interface-assignment API reports a manual step. Kea and advertised client DNS options require operator configuration. Existing active switch ports retain their profiles. Use the separate port role plan to review a selected port before binding a profile.

Pass `--ssid` or `ssid` to verify an enabled, secured WLAN assigned to this tag. A missing or unrecognized WLAN needs controller configuration, including wireless credentials. Downstream checks wait for the requested WLAN. A partial run records which steps completed, which need review and which are waiting. Re-run the plan after reconciling an interrupted operation at the owning controller. Each apply reads current configuration and checks the result of a write before advancing.

For source verification, set `NYX_SEGMENT_VERIFICATION_SPEC` on the Nyx process to an operator-owned intent file. Declare the same network role, tag and CIDR. Declare a probe with a literal address in the requested DHCP pool and two `service_policies` from that probe. One measures DNS against the selected resolver and an expected answer. The other measures denial of one TCP service inside the protected management prefix. Each has a positive control in its destination zone. Nyx looks for the source probe's active lease and runs only those measurements and controls. The result describes these IPv4 checks. IPv6 policy, other services, and physical AP enforcement require their own evidence.
